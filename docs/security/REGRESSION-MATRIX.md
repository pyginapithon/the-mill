# Security regression matrix

Each row ties a hardened behavior to the behavior test(s) that lock it in.
Add a row when a security fix lands; keep rows free of exploit detail beyond
what the linked test needs.

| S-8 | The pack check sees the same history in CI as on a full local clone.
